# Typography provenance / Procedencia tipográfica

Inter 4.1, Rasmus Andersson. Official release: https://github.com/rsms/inter/releases/tag/v4.1
Source archive: https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip
Desktop files are unchanged extras/ttf/Inter-Regular.ttf and extras/ttf/Inter-SemiBold.ttf.
Web files are unchanged web/Inter-Regular.woff2 and web/Inter-SemiBold.woff2.
Both use weights 400 and 600. No modified font files or additional weights are included.
The original SIL Open Font License 1.1 is included as Inter-OFL-1.1.txt in both font folders so each handoff is self-contained.
