# Phosphor assets

Source: `IGNACIO_BELITZKY_Phosphor_Essential_Kit_v1.0.zip`, supplied by Ignacio Belitzky for the developer introduction.

The primary 2048 px PNG, Inter Regular TTF, font license and provenance are byte-for-byte copies. See `docs/navigation/brand-sources.json` for their original paths and SHA-256 hashes. The logo includes its approved dark disc and 1X outer protection; retain its square proportions and white UI tint. Do not redraw, recolor, rotate, crop or add glow to it.

The Intro uses the approved dark background `#071C13`, primary interface text `#F5FAF7`, secondary text `#A8C0B1`, and Inter Regular. TextMeshPro creates a scene-local dynamic font atlas from the included font. The atlas, material and font instance are released when Intro unloads.
