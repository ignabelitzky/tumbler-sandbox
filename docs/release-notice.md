Linux: extract the entire ZIP, preserve permissions and run ./TumblerSandbox.x86_64.
If your extractor removes permissions: chmod +x TumblerSandbox.x86_64.
Windows: extract the entire ZIP and run TumblerSandbox.exe.
Keep the executable, UnityPlayer, Data and MonoBleedingEdge folders together.
An HDRP-capable GPU/driver is required; Unity Editor is not required to play.
